CALL PROCESSING API (/api/v1/call-processing/process)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Per Call Processing Request, we make the following LLM calls:

1. DIARIZATION SERVICE (3 LLM calls)
   - diarization_service.py
     ├─ identify_speakers() - 1 call
     ├─ label_speakers() - 1 call
     └─ verify_diarization() - 1 call

2. CALL TYPE DETECTOR (1 LLM call)
   - call_type_detector.py
     └─ detect_call_type() - 1 call

3. SUMMARY EXTRACTOR (1 LLM call per chunk)
   - summary_extractor.py
     └─ extract() - 1 call per chunk
     Note: Typically 3-5 chunks per call

4. COMPLIANCE EXTRACTOR (1 LLM call per chunk)
   - compliance_extractor.py
     └─ extract() - 1 call per chunk
     Note: Typically 3-5 chunks per call

5. OBJECTION EXTRACTOR (4 LLM calls)
   - objection_extractor.py
     ├─ _stage1_initial_detection() - 1 call
     ├─ _stage3_llm_classification() - 1 call
     ├─ _stage6_validate_speakers() - 1 call
     └─ _stage7_cross_validate_objections() - 1 call

6. QUALIFICATION EXTRACTOR (4 LLM calls per chunk)
   - qualification_extractor.py
     ├─ _extract_core_qualification() - 1 call per chunk
     ├─ _extract_appointment_details() - 1 call per chunk
     ├─ _extract_customer_intelligence() - 1 call per chunk
     └─ _extract_property_details() - 1 call per chunk
     Note: Typically 3-5 chunks per call

7. SUMMARY MERGE (1 LLM call)
   - summary_service.py
     └─ _merge_chunk_summaries_with_llm() - 1 call
